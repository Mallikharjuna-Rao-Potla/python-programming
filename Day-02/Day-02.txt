Variables in Python

1. Don't start with the variable name by a digit
2. variable name must be start with character or underscore.
3. Special symbols are not allowed in variable name.
4. hypen and spaces are not allowed inside the name. 

sample Code:

a = 10
b = 12.43
c = "Mallikharjun"
d = True
e = None

print(type(a))
print(type(b))
print(type(c))
print(type(d))
print(type(e))

output:<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
